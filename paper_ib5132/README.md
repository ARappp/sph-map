# Input data and scripts for: Directional analysis of electron-density maps by spherical-harmonic Fourier filtering

Santosh Panjikar, Manfred S. Weiss and Dylan Jayatilaka. *Acta Cryst. A*, manuscript IB5132 (revised version).

This record contains the **input data** and the **scripts** that compute every number, table and figure of the
paper and its Supplementary material. Results are not included: they are regenerated by running the steps below,
and each step checks its results against reference values stored with the scripts.

Software: sph-map 11.8.0 (https://github.com/ARappp/sph-map), Python 3.10 or later with numpy, scipy, pandas,
gemmi 0.7, matplotlib; Fig. 3 also needs PyMOL (pymol-open-source) and Pillow. The environment used for the paper
is `environment-paper.yml` of the sph-map repository.

## Use within the sph-map repository

This folder holds the same scripts as the Zenodo record of the paper, without the input data. Download the record
(DOI in the main `README.md` of the repository) and either run the steps there, or copy or link its
`01_input_data/` folder into this folder and run the steps below from here.

## How to run

```
conda activate sph-map-ib5132          # environment with sph-map installed
cd ib5132_zenodo
sh 02_prepare/run.sh          && python3 tools/check_step.py 02_prepare
sh 03_filter/run.sh           && python3 tools/check_step.py 03_filter
sh 04_small_molecules/run.sh  && python3 tools/check_step.py 04_small_molecules
sh 05_hydrogen_tests/run.sh   && python3 tools/check_step.py 05_hydrogen_tests
sh 06_6mu9/run.sh             && python3 tools/check_step.py 06_6mu9
sh 07_pdbredo/run.sh          && python3 tools/check_step.py 07_pdbredo
sh 08_figures/run.sh
```
Results are written to `work/<step>/` (set `IB5132_WORK` to write elsewhere; set `IB5132_SPHMAP` if sph-map is not on
the PATH). Every path is defined once, in `config.py`. Each check ends with `... -> OK` when all result files agree
with the reference values (MTZ/CCP4 statistics to 1e-5 of the largest value; numbers in JSON/CSV/NPZ files to
2e-3 + 2e-4 |value|, well below the precision quoted in the paper), since the last digits can differ between computers and numpy/FFT builds.

## Steps

| Step | Content | Time* |
|---|---|---|
| `02_prepare` | Gly–Ala HAR `.fcf` → MTZ (Friedel pairs merged); P1 symmetry expansion of urea and Gly–Ala; IAM, IAM-phase and deformation sets | 1 s |
| `03_filter` | sph-map with the settings of the paper (urea, Gly–Ala: observed, IAM, IAM-phase, deformation) | 15 s |
| `04_small_molecules` | numerical checks (incl. Plancherel), bond descriptors, sampling windows, profiles, incomplete data, radial weights, grid vs exact sums, taper | 1 min |
| `05_hydrogen_tests` | known-H test with phase controls P1–P4, model-phase control, taper, H-omit peaks | 25 s |
| `06_6mu9` | carbonyl observed–model angles for four reference models, resolution sweep with tapers, coordinate robustness, difference peaks, amide-H test, aromatic rings and backbone classes | 7 min |
| `07_pdbredo` | P1 and H-omit coefficients, exact site values, amide-H test with controls for the five PDB-REDO entries | 6 min |
| `08_figures` | data for and drawing of Figs 1–5 and S1–S6 | 3.5 min |

\*measured on a two-core cloud machine; the whole pipeline takes about 18 min and needs about 1 GB of disk for `work/`. `lib/` holds the code shared by the steps.

## Conventions

- sph-map 11.8.0 with the settings of the paper: `-lmax 1 --phase-convention ccp4 --symmetry-policy p1_complete_friedel
  --norm none --taper none --radial-weight-convention crystallographic_q --shell-weights off`; 6 grid points per d_min
  for urea and Gly–Ala. F(000) is omitted from the maps.
- Site values for the proteins are exact Fourier sums at each site (no map interpolation). The sphere-averaged field
  ⟨d⟩ (Eq. 7) uses the points of a 0.1 Å cubic lattice with |p| ≤ r0, surface points included, decided with exact
  integer arithmetic (`lib/lattice.py`): 123 points for r0 = 0.3 Å and 925 for r0 = 0.6 Å.
- Gly–Ala: 22 of the 5100 expanded reflections have F_obs = 0 (negative intensities set to zero when Friedel pairs
  were merged); they are excluded from the mean HAR–IAM phase difference.

## Input data (`01_input_data`)

| Folder | Content |
|---|---|
| `urea/` | observed amplitudes with HAR phases (`urea_Fphi.mtz`), HAR model (`urea.archive.cif`, `urea_HAR_model.pdb`) |
| `gly-ala/` | 150 K data with the HAR of 18 October 2026: `gly_L_ala.archive.fcf` (observed and HAR structure factors), `gly-ala.cif` (HAR model), `glyala_HAR_model.pdb` (coordinates from the CIF, B = 8π²U_eq) |
| `6mu9/` | deposited model (`6MU9_deposited.pdb`; also the model shown in all 6MU9 figures), REFMAC map coefficients (`6mu9_final.mtz`), coordinates of an intermediate refinement file (`6mu9_final.pdb`; used only for the check in the Supplementary), re-refinement input (`rerefinement_input_nat_ext_hi.mtz`) and the Phenix re-refined models (a) no H, (b) riding H and (c) riding H plus H on O299 with their MTZ files |
| `pdbredo/` | the five PDB-REDO entries of the resolution series (4Y44, 3X3R, 3UME, 3LA9, 4GYB): final model and map coefficients |

### Sources

- Urea: synchrotron data of Birkedal *et al.* (2004), *Acta Cryst.* A60, in the form used for HAR by Hupf *et al.*
  (2023); CCDC 2182609 (the CCDC file itself is not redistributed here).
- Gly–Ala: synchrotron data measured at 150 K on beamline ID11 of the ESRF by Capelli *et al.* (2014), *IUCrJ* 1,
  361–379; HAR (restricted Kohn–Sham, B3LYP/def2-TZVP) in Tonto, 18 October 2026.
- 6MU9: Protein Data Bank entry 6MU9; models (a)–(c) re-refined with Phenix for this work.
- PDB-REDO entries 4Y44, 3X3R, 3UME, 3LA9, 4GYB (Joosten *et al.*, 2014).
